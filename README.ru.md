# 3D Print Calculator

[English](README.md) · **Русский**

Калькулятор себестоимости 3D-печати и учёт печати для домашнего использования. Считает реальную стоимость печати, хранит каталог ваших моделей, ведёт склад катушек филамента и журнал печати. Без сервера и регистрации: данные хранятся в браузере, в папке на компьютере или в вашем Google Drive.

**Сайт:** https://fomins.github.io/3d-print-calculator/

Сделан под Bambu Lab P2S Combo, но подходит для любого FDM-принтера.

## Возможности

### Калькулятор
- Себестоимость по статьям: пластик, электричество, амортизация принтера, обслуживание, дополнительные затраты.
- Время печати — часы и минуты, слайдер от 0 до 48 ч. Можно вводить дробные часы (`2,5`) или `2:30`.
- Выбор принтера. Прототипы (пробные печати) считаются отдельно как затраты на разработку.
- Сохранение в каталог в один клик с переходом в карточку изделия.

### Каталог и карточка изделия
- Статус (идея / в работе / готово / опубликовано), теги, примечания, принтер, дополнительные затраты.
- Ссылки с быстрыми кнопками MakerWorld, Thingiverse, Printables. Название сайта подставляется по адресу.
- **Элементы**: количество, время, несколько материалов в одном элементе (AMS). Стоимость по каждому элементу и по изделию.
- **Прототипы**: версия, дата, материал, катушка, время, заметка «что проверяли / что изменили».
- Настройки печати, фото (хранятся в выбранном хранилище, уменьшаются до 1600 px), обложка.
- **Генератор описания для MakerWorld** (RU/EN) из элементов и настроек печати.

### Катушки
- Производитель, серия, цвет, вес нетто, диаметр, цена, магазин, даты покупки, вскрытия и сушки.
- Остаток в граммах и метрах, предупреждение «мало», история изменений.
- Корректировка остатка вручную (граммы или метры) или взвешиванием. Вес пустой катушки вычисляется по новой запечатанной.
- **Справочники** в настройках:
  - производители с их сериями;
  - магазины;
  - палитра цветов, включая **многоцветные и радужные** (градиент).
- В карточке катушки значения выбираются быстрыми кнопками. Новые значения запоминаются сами, а переименование в справочнике применяется к катушкам.

### Журнал печати
- «Записать печать» в карточке изделия списывает пластик с выбранных катушек. Неудачные печати тоже учитываются.
- Просмотр по месяцам, по годам или общим списком, с итогами за период: записи, комплекты, неудачные, филамент, себестоимость.

### Статистика
- Итоги и средние, структура затрат, разбивка по материалам и месяцам.
- Затраты на прототипы, филамент на складе, выработка ресурса каждого принтера.

### Принтеры
- Несколько принтеров, у каждого стоимость, срок амортизации, часы в год, мощность и обслуживание. По умолчанию — Bambu Lab P2S.
- Принтер выбирается для изделия и для каждой печати.

### Хранение и синхронизация

| Хранилище | Где | Устройства | Фото |
|---|---|---|---|
| Браузер | IndexedDB текущего браузера | только этот браузер | — |
| Папка | `3d-print-data.json`, `photos/`, `backups/` в выбранной папке | Chrome / Edge на компьютере | ✓ |
| Google Drive | папка `3D Print Calculator/` в вашем Google Drive | любой браузер, включая телефон | ✓ |

- Копия в браузере есть всегда. Выбранное хранилище сохраняется автоматически или вручную по `Ctrl+S`.
- Перед перезаписью файла данных прежняя версия сохраняется в `backups/`.
- Google Drive: изменения с другого устройства подхватываются при возврате во вкладку, но не во время ввода. Настоящие конфликты определяются по содержимому файла (MD5). Вы выбираете, какую версию оставить, вторая уходит в резервную копию.
- Если сайт открыт в нескольких вкладках, появляется предупреждение.

### Прочее
- Светлая и тёмная тема или как в системе.
- Резервная копия и импорт JSON, экспорт CSV.
- Можно установить как приложение на телефон или компьютер.

## Формула

```
C = M × P / 1000 + T × W / 1000 × E + T × A + T × R + X
A = Стоимость принтера / (Срок амортизации в годах × Часов печати в год)
```

| Обозначение | Что это |
|---|---|
| M | Расход пластика, г (с поддержками и отходами) |
| P | Цена пластика за кг |
| T | Время печати, ч |
| W | Средняя мощность принтера, Вт |
| E | Тариф на электроэнергию, ₽/кВт·ч |
| A | Амортизация за час печати (у каждого принтера своя) |
| R | Обслуживание за час печати (у каждого принтера своё) |
| X | Дополнительные затраты |

Прототипы считаются по той же формуле и показываются отдельно. Оплата труда и прибыль не включены.

## С чего начать

1. Откройте https://fomins.github.io/3d-print-calculator/.
2. **Настройки**: цены материалов, принтер(ы), тариф на электричество.
3. Выберите хранилище: **папку** на компьютере или **Google Drive**.
4. Добавьте катушки в разделе **Катушки**, изделия — через **Калькулятор**, а печати записывайте из карточки изделия.

> Данные браузера привязаны к адресу сайта. Если раньше калькулятор открывался как локальный файл, зайдите в **Настройки → Выбрать папку** и укажите папку с `3d-print-data.json`.

## Подключение Google Drive

Для сайта нужен OAuth Client ID от Google. Его один раз получает владелец сайта.

**Подробная пошаговая инструкция с решением ошибок: [docs/google-drive-setup.md](docs/google-drive-setup.md).**

Кратко:

1. [Google Cloud Console](https://console.cloud.google.com/): создать проект, включить **Google Drive API**.
2. **Google Auth Platform**: аудитория *External*, добавить себя в **Test users**.
3. **Clients → Create client → Web application**, *Authorized JavaScript origins*: `https://fomins.github.io` (и `http://localhost:8000` для локальной проверки).
4. Вписать Client ID в `js/config.js`, сделать commit и push.

Приложение использует доступ `drive.file`: оно видит только созданные им файлы, остальной Google Drive ему недоступен. Client ID публичный. Вход действует около часа, переподключение — один клик, а изменения за это время сохраняются в браузере.

## Запуск на компьютере

Вход Google не работает при открытии файла напрямую (`file://`), поэтому запускайте через локальный сервер:

```
python -m http.server 8000
```

Затем откройте http://localhost:8000. Публикация на GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Структура проекта

```
index.html                 разметка
css/style.css              стили, светлая и тёмная темы (CSS-переменные)
js/config.js               настройки: Google Client ID
js/gdrive.js               хранилище Google Drive
js/app.js                  приложение
docs/google-drive-setup.md инструкция по подключению Google Drive
manifest.webmanifest       установка как приложения
```

Чистые HTML, CSS и JavaScript, без сборки и зависимостей. Личные данные (`3d-print-data*.json`, `photos/`, `backups/`) исключены через `.gitignore`.
